# Lam3a Car Care 🚗🏍️💦

موقع ولوحة تحكم لمغسلة **Lam3a Car Care** (كان اسمها Turbo Wash) للسيارات والموتوسيكلات — باك إيند (Node.js + Express + SQLite) وفرونت إند عربي RTL بدون فريمورك.

> **حالة التحقق بصراحة:** بيئة البناء ممنوعة من `npm install`، فمقدرتش أشغّل السيرفر الحقيقي (express + better-sqlite3 الأصلية). اللي اتجرب فعلاً:
> - كود الـ routes الحقيقي (العملاء، الزيارات، الداشبورد، المخزن، الحساب) اتشغّل على SQLite حقيقية عبر بيئة اختبار بديلة: **95 اختبار نجحوا** (حسابات الخصم، الإحصائيات مقارنةً بحساب مستقل، المخزن، تغيير اسم المستخدم/الباسورد، البيانات التجريبية، التحقق من المدخلات).
> - الواجهة اتجربت في متصفح حقيقي (Playwright) فوق نفس الـ routes: **40 فحص نجحوا** (الداشبورد، النوافذ، الفلاتر، العملاء، المخزن، الإعدادات، الدخول، الموبايل).
> - **لم يتم** اختبار: طبقة express نفسها (helmet / rate-limit / كوكي JWT / multer)، ولا bcrypt الحقيقي، ولا ExcelJS الحقيقي. دول هيتختبروا عندك بـ `npm test` بعد `npm install`. لو ظهر أي خطأ ابعتهولي.

## المميزات

**الموقع العام (`/`)** — Hero، العروض (من الداتابيز، العروض المنتهية بتختفي تلقائياً)، الخدمات والأسعار، معرض الصور، بيانات التواصل، وزرار واتساب. الزائر مبيشوفش أي بيانات عملاء.

**لوحة التحكم (`/admin`)** — محمية بتسجيل دخول:
- **الرئيسية:** 6 بطاقات لإجمالي اليوم (الإيراد والخصم قابلين للضغط وبيفتحوا قائمة عملاء اليوم / عملاء الخصم)، الإيراد حسب فترة تاريخ، تقرير الإيرادات الشهرية (من شهر لشهر)، إحصائيات استخدام كل خدمة (فترة + شهر + إجمالي)، العملاء المتوقفون 14 يوم أو أكتر مع زرار متابعة واتساب، وأعياد الميلاد.
- **العملاء:** إضافة/تعديل/حذف، بحث، استيراد وتصدير Excel، أعمدة: الاسم، الموبايل، الميلاد، تاريخ التسجيل، الزيارات، الخصم. صفحة العميل فيها: عدد الزيارات، إجمالي المدفوع، إجمالي الخصم، وسجل الزيارات.
- **الزيارات:** خدمات و/أو عرض، السعر والمدفوع (الافتراضي = السعر). **مفيش "متبقي":** أي فرق بين الإجمالي والمدفوع بيتسجّل **خصم** (مثال: حساب 500 ودفع 300 ← خصم 200).
- **الخدمات والأسعار، العروض، معرض الصور.**
- **المخزن:** منظفات / مستهلكات / مستلزمات، بحث بالاسم أو الكود، فلتر الحالة (متوفر / منخفض / نفدت)، كود تلقائي (CHM-/CON-/SUP-)، إضافة وصرف وجرد كمية (↕)، وبطاقات إجمالي القيمة والتنبيهات.
- **الإعدادات:** الحساب (تغيير اسم المستخدم وكلمة المرور بزرار إظهار/إخفاء) وبيانات التواصل.

**ملاحظات تصميم:** الإيراد بيتحسب من مدفوع الزيارة حسب **تاريخ الزيارة**. الزيارات القديمة (قبل التحديث) بيتم تحويلها تلقائياً مرة واحدة: سعر الزيارة = اللي اتدفع فعلاً، والباقي بقى خصم. الداتابيز القديمة `turbowash.db` شغالة زي ما هي (الاسم الافتراضي للملف لسه `turbowash.db` عشان بياناتك ما تضيعش).

## التشغيل محلياً

المطلوب: **Node.js 18 أو أحدث** (الأفضل 20 أو 22).

```bash
cd lam3a-car-care
npm install          # تثبيت الحزم
npm run setup        # ينشئ ملف .env بمفتاح JWT عشوائي وباسورد أدمن عشوائي (هيتطبع في الشاشة)
npm run seed         # (اختياري) بيانات تجريبية وهمية
npm test             # (اختياري) اختبار شامل على قاعدة بيانات مؤقتة
npm start            # تشغيل السيرفر
```

بعدها افتح:
- الموقع: <http://localhost:3000>
- لوحة التحكم: <http://localhost:3000/admin> (اسم المستخدم `admin` وكلمة المرور اللي اتطبعت في `npm run setup`)

أوامر مفيدة:
```bash
npm run dev                                   # تشغيل مع إعادة تحميل تلقائي
npm run seed:clear                            # مسح البيانات التجريبية فقط
npm run reset-admin -- admin كلمة_مرور_جديدة   # نسيت الباسورد؟ (8 أحرف على الأقل)
```

> لو `npm install` فشل في `bcrypt` أو `better-sqlite3` على ويندوز، ثبّت أدوات البناء (Visual Studio Build Tools) أو استخدم Node LTS لأن الحزم بتنزل جاهزة (prebuilt) لأغلب الإصدارات.

## متغيرات البيئة

كلها في ملف `.env` (انسخ `.env.example` أو شغّل `npm run setup`). **ممنوع** ترفع `.env` على GitHub.

| المتغير | الوصف |
|---|---|
| `NODE_ENV` | `development` محلياً، `production` على الاستضافة |
| `PORT` | البورت (الاستضافة بتحدده تلقائياً) |
| `JWT_SECRET` | سر التوقيع، **32 حرف عشوائي على الأقل**. السيرفر مش بيشتغل من غيره |
| `JWT_EXPIRES` | مدة الجلسة (افتراضي `12h`) |
| `ADMIN_USER` / `ADMIN_PASSWORD` | بيانات الأدمن اللي بتتنشئ **أول تشغيل بس** لو مفيش أدمن (الباسورد 8 أحرف+) |
| `DB_PATH` | مسار ملف قاعدة البيانات |
| `UPLOADS_DIR` | مسار الصور المرفوعة |
| `APP_TIMEZONE` | افتراضي `Africa/Cairo` (لحساب "النهارده" و"الشهر") |
| `COOKIE_SECURE` | اختياري. الكوكي بيبقى Secure تلقائياً في production؛ خليها `false` لو بتجرب production على http محلي |

## البيانات التجريبية

`npm run seed` بيضيف 20 عميل **وهمي** (أرقام `0100000xxxx`) وزيارات ومدفوعات وعروض وصور معرض (رسومات SVG) و9 أصناف مخزن (قيمتها 10,640 ج.م و4 تنبيهات)، كلهم معلّمين `is_demo`. `npm run seed:clear` بيمسحهم من غير ما يلمس بيانات عملائك الحقيقية. الأسعار الافتراضية للخدمات تقريبية للتجربة — عدّلها من لوحة التحكم.

بيانات التواصل (الموبايل والعنوان والمواعيد) موجودة كـ **أماكن مؤقتة بين أقواس `[...]`** لحد ما تعدّلها من **الإعدادات**.

## استيراد العملاء من Excel

من **العملاء ← استيراد من Excel**:
1. حمّل القالب الجاهز (أو استخدم ملفك). الصف الأول عناوين: `الاسم` و`رقم التليفون` و`تاريخ الميلاد` (الميلاد اختياري). بيتعرف كمان على `Name` / `Phone` / `Birthday`.
2. اضغط **معاينة**: هتشوف كام عميل جديد وكام صف هيتخطى وسببه (رقم غلط، مكرر في الملف، موجود بالفعل).
3. اضغط **استيراد الصالح**.

الصيغ المدعومة: `.xlsx` و`.csv` (حتى 5 ميجا و5000 صف). التواريخ: `2024-05-31` أو `31/05/2024` أو تاريخ إكسل عادي. الأرقام اللي الإكسل شال منها الصفر (`1012345678`) بتتصلح تلقائياً.

## الأمان

- كلمات المرور متشفرة بـ **bcrypt (12 rounds)**؛ مفيش أي سر مكتوب في الكود، كله من `.env`.
- **JWT** في كوكي `HttpOnly` + `SameSite=Strict` (+ `Secure` في production)، وكل مسارات العملاء/الزيارات/الخدمات/العروض/المعرض/الإعدادات/الداشبورد بتتحقق منه.
- **rate limit** على تسجيل الدخول: 10 محاولات كل 15 دقيقة.
- **helmet** مع Content-Security-Policy، وفحص `Origin` على الطلبات اللي بتغيّر بيانات.
- كل استعلامات SQL **prepared statements**، والتحقق من المدخلات (رقم مصري، أسعار موجبة، المدفوع ≤ السعر، الدفعة ≤ المتبقي) بيتم **في السيرفر** مش بس في المتصفح.
- رفع الصور: JPG/PNG/WEBP بحد 5 ميجا، ويتم فحص **محتوى الملف الحقيقي** وبيتخزن باسم عشوائي.
- الأخطاء غير المتوقعة بترجع رسالة عامة (التفاصيل في سجل السيرفر بس).
- العمليات المتعددة (زيارة + خدماتها + دفعتها الأولى، استيراد Excel) بتتم داخل **transactions**.

## الرفع على Render

> لازم استضافة بتدعم Node.js (**مش GitHub Pages**).

1. ارفع المشروع على GitHub (من غير `.env` — موجود في `.gitignore`).
2. في Render: **New ← Web Service** واختار الريبو.
3. الإعدادات: **Runtime:** Node — **Build Command:** `npm install` — **Start Command:** `npm start`.
4. **Persistent Disk** (انظر [التخزين الدائم](#مهم-جداً-التخزين-الدائم)): من تبويب *Disks* أضف Disk واعمل Mount Path = `/var/data`. (الـ Disk محتاج خطة مدفوعة على Render.)
5. من *Environment* أضف المتغيرات:
   - `NODE_ENV=production`
   - `JWT_SECRET=` قيمة عشوائية طويلة (ولّدها بـ `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`)
   - `ADMIN_USER=admin` و`ADMIN_PASSWORD=` باسورد قوي
   - `DB_PATH=/var/data/turbowash.db`
   - `UPLOADS_DIR=/var/data/uploads`
6. اضغط **Deploy**. افتح `https://اسم-مشروعك.onrender.com/admin` وسجّل دخول، وغيّر الباسورد من الإعدادات.
7. (اختياري) لو عاوز بيانات تجريبية: من تبويب *Shell* شغّل `npm run seed`، وبعد ما تخلص امسحها بـ `npm run seed:clear`.

## الرفع على Railway

1. ارفع المشروع على GitHub، وفي Railway: **New Project ← Deploy from GitHub repo**.
2. أضف **Volume** من *Settings ← Volumes* واعمل Mount Path = `/data`.
3. من *Variables* أضف نفس المتغيرات، مع:
   - `DB_PATH=/data/turbowash.db`
   - `UPLOADS_DIR=/data/uploads`
   - `NODE_ENV=production`
4. من *Settings ← Networking* اعمل **Generate Domain**. Railway بيستخدم `npm install` و`npm start` تلقائياً.
5. افتح `/admin` وسجّل دخول.

## مهم جداً: التخزين الدائم

قاعدة البيانات (SQLite) والصور المرفوعة **ملفات على القرص**. أغلب الاستضافات بتمسح القرص المؤقت مع كل Deploy أو Restart، يعني **من غير Persistent Disk / Volume هتفقد كل العملاء والزيارات والصور**. لازم:
- تعمل Disk/Volume وتوجّه `DB_PATH` و`UPLOADS_DIR` ليه (زي الخطوات فوق).
- تشغّل **نسخة واحدة فقط** من التطبيق (SQLite مش مناسب لتشغيل أكتر من instance).
- لو فضلت تستخدم خطة مجانية من غير Disk، المشروع هيشتغل لكن البيانات هتضيع — مش مناسب للإنتاج.

## النسخ الاحتياطي

انسخ دورياً ملف `DB_PATH` (ومعاه ملفات `-wal` و`-shm` لو موجودة) ومجلد `UPLOADS_DIR`. الأفضل توقف السيرفر لحظة النسخ أو تستخدم `sqlite3 turbowash.db ".backup backup.db"`.

## حدود المشروع الحالية

- أدمن واحد أو أكتر بنفس الصلاحيات (مفيش أدوار).
- مفيش حجز مواعيد أونلاين ولا بوابة دفع إلكتروني.
- الإيراد بيتحسب على تاريخ **الزيارة**. مفيش تسجيل دفعات إضافية لاحقة (الدفع بيتحدد وقت تسجيل/تعديل الزيارة).
- الخط (Cairo) بيتحمل من Google Fonts؛ لو الإنترنت فاصل بيتعرض خط النظام العربي.
- مفيش صور حقيقية للمغسلة جوه المشروع — الصور الموجودة رسومات تجريبية، ارفع صورك من **معرض الصور**.
